# 广场游戏接入

`/square/` 的内容区首先展示校园工具箱，游戏介绍和入口排在后面；默认只保留校园工具箱和筹备提示。构建时明确设置 `SQUARE_GAMES_ENABLED=true` 才展示弹射冰球与恰好合拍入口；未设置或其他值均隐藏。该开关在构建时写入静态产物，启用或关闭都需要重新构建并发布，修改运行环境不会改变已发布页面。Ops 的官网发布流程提供默认关闭的 `enable_square_games` 输入。

内容、玩法说明、封面和 URL 集中在 `src/features/square/content/square.ts`；静态 SVG 封面位于 `public/assets/games/`。卡片只展示入口，不预加载游戏引擎。隐藏卡片不是认证开关，直接访问游戏和启动页仍需后端、游戏服务各自验证身份。

## 访问路径

- 弹射冰球：`https://games.northward.zone/hockey/`
- 恰好合拍：`https://games.northward.zone/perfect-match/`

这两个地址由个人游戏服务器承载，官网只负责展示入口。部署配置见 `northward-ops/nginx/games.northward.zone.conf`，完整操作顺序见该仓库的 `docs/广场游戏部署.md`。

普通同窗口链接会被现有 App 广场 WebView 拦截并打开完整 WebView 页面，保留原生返回和关闭；浏览器则在当前标签页打开游戏。不要改为 `target="_blank"`、自动跳转、iframe 或 `window.open`。游戏使用独立来源，保持 App 的官网 token 白名单不变。

## 发布顺序

**当前代码不代表新游戏域已上线。可以先发布默认隐藏游戏的官网产物；公开游戏入口前必须完成游戏域部署和验收。**

1. 为 `games.northward.zone` 配置 DNS 与有效 TLS，部署个人服务器专用站点。
2. 验证两个游戏的静态资源、排行榜、冰球匹配与 WSS。确认旧 HTTP IP 游戏入口和网盘仍正常。
3. 使用候选官网页面完成 iPhone 竖屏和 Android 真机检查：点击进入、拖动、声音解锁、返回、关闭、切后台与恢复。没有候选站点时，先直接验收 HTTPS 游戏，再在官网发布后立即验证 App 广场链路。
4. 检查与构建官网，再通过既有官网发布流程部署。只有前三步通过后才明确启用 `enable_square_games`；游戏域未就绪时保持默认关闭。

旧 IP 的 localStorage 和匿名 Cookie 不会跨来源迁移到新域，原服务器榜单数据保留。新增账号交接通过官网固定启动页与独立游戏会话完成；旧匿名进度不自动认领，历史进度迁移、App 横屏和无边框全屏改造仍不在本轮范围。

## 本地检查

运行 `npx astro check`、`npm run build`，再从构建产物预览 `/square/`，覆盖桌面、320px 手机、深色模式、App 嵌入模式和减少动画设置。检查两张卡片有可见键盘焦点，普通浏览器点入后可返回。模拟目标页面只能验证导航，不能当作线上游戏或真机验收。

回退时先回退官网广场入口，再按 ops 文档回退新增游戏站点；不要删除游戏数据或停止原有游戏服务。

无感账号配置与验收见 Ops 的 `docs/广场游戏账号接入.md`。卡片链接的 `northward=1` 只表示重新建立账号上下文，不含任何凭据。

## 账号等待与回归范围

普通浏览器没有 App 注入标记时直接进入游客模式。App 先注入主题标记、后提供登录态时，启动页等待 `northwardAuthChanged`，最多 45 秒；超时或登录码签发失败显示「重新进入」，不会静默改为游客记分。主 token 仅发送到官网同源签发接口，游戏只接收一次性登录码及独立会话。

`npm run test:games` 默认覆盖两个游戏的真实浏览器登录模块，需同级游戏仓库；可用 `GAMES_TEST_ROOT` 指定仓库父目录，`GAMES_TEST_GAME_IDS=hockey` 仅跑冰球。公开官网 CI 使用冰球并验证开关关闭/开启两种构建；私有合拍仓库 CI 固定公开依赖提交，运行两个游戏的浏览器回归。真实游戏服务使用独立联调脚本验证：Ops CI 跑公开冰球，私有合拍 CI 使用从 Ops 纳入的脚本跑两个真实服务，无需公开仓库持有私有仓库凭据。

浏览器回归覆盖换号、退出、弱网重试、延迟原生认证、45 秒超时及重试、PKCE/state、错误/过期回调和 320px 布局。浏览器接口为模拟响应；真实服务联调也模拟上游登录码兑换。这些检查不替代生产 TLS、后端与游戏完整网络链路、iOS/Android 真机 Cookie/WSS/前后台切换验收。
